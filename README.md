# 忍桜郷 公式サイト

HTML・CSS・JavaScriptで動く、忍桜郷の静的ホームページです。ビルドや追加のサービス設定は不要です。

## この改修について

- 既存の紋章と住人の写真を使った、墨色・淡桃・生成りのデザイン。
- トップページに世界観、開催概要、訪れ方、住人紹介、公式Xへの案内を整理。
- 既存40名の性格・紹介文・Xリンクと、7名に付いていた別れの記述を継承。
- 名前・読み・種族・紹介文での検索。ひらがな・カタカナ・半角カナにも対応。
- 住人一覧は「郷の住人」を初期表示。「思い出の住人」「すべて」に切り替え可能。
- トップページに、RPと撮影についてのFAQを掲載。
- 写真と紹介文を開くダイアログ、Escapeでの終了、終了後のフォーカス復帰。
- スマートフォン対応、WebP画像、遅延読み込み、日本語フォントの同梱。

「思い出の住人」は、`data-state="memory"` が設定された住人です。分類と別れの記述は運営の指定に沿って更新します。
開催時刻は旧ページの「毎週火曜22:00 JST（目安）」を継承し、受付条件は公式Xの最新告知へ案内しています。

## GitHubとVercelへの反映

1. ZIPを展開します。`index.html` と `assets` が同じ階層にあることを確認してください。
2. GitHubの `blancwindgrace-source/ninoukyo-web` を開き、`Add file` → `Upload files` から、展開したファイルと `assets` フォルダーをまとめて追加します。
3. `index.html`・`members.html`・`styles.css` は同名のファイルを更新し、`site.js` と `assets/` を追加します。ZIPそのものや、展開した外側のフォルダーをアップロードする方法では反映されません。
4. 既存の `casts/` はそのまま残せます。コードはその原寸PNGを変更・削除しません。
5. 変更をコミットします。Vercelでこのブランチの自動デプロイが有効なら反映が始まります。Vercelのデプロイ結果を確認し、公開ページを開いてください。

ローカルで見る場合は、展開後の `index.html` をブラウザーで開けます。ファイルと `assets` フォルダーを同じ位置に置いてください。

## 文章と写真の更新

FAQは `index.html` の `id="faq"` 内にあります。質問は `dt`、回答は `dd` を編集します。

`members.html` の `<article class="member" ...>` が1名分です。性格は `memberMeta`、紹介文は `memberBio` にあります。
写真の小さい表示は `memberPhoto` の画像、大きい表示は `castBtn` の `data-img` を参照します。写真を変更するときは両方のパスを更新してください。

写真が未掲載の住人は、白桜・朧・結音愛・蒼月・晴・紅姫・紅狼・天椿・さくやひめの9名です。元のリポジトリに指定画像がないため、紋章と「写真未掲載」を表示しています。

1名追加する場合は既存の `article` を複製し、次を更新します。

- `id="member-識別名"` と、同じカード内のすべての `data-profile="識別名"`。
- `data-name`・`data-reading`・`data-img`・`data-x`、写真の `src`、名前・読み・種族・紹介文。
- 現在の住人は `data-state="present"`、別れの記録がある住人は `data-state="memory"`。
- リンクの `href`、`alt`、`aria-label` も、新しい住人に合わせます。

件数はHTML内のカードから自動計算します。フォントには現在のページで使用する文字を収録しています。追加した漢字が含まれない場合は、端末の日本語フォントで補完されます。

## 素材

写真と紋章は既存リポジトリの素材です。生成画像や架空の住人写真は使用していません。
原寸写真を保持し、表示用にリサイズ・WebP変換しています。拡大表示は写真全体を表示します。
Noto Serif JP・Noto Sans JPをサブセット化して同梱しています。ライセンスは `assets/fonts/` 内のOFLファイルをご覧ください。
